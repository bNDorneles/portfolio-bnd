# Bernardo Dorneles — Portfolio

Personal portfolio of Bernardo Gomes Dorneles — Software Engineering student at UNIPAMPA and developer focused on backend, systems, and AI.

**Live:** [https://portfolio-bnd.vercel.app](https://portfolio-bnd.vercel.app)

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```

## Content

Copy and project data live in `src/content/` (`pt.ts` / `en.ts`). Update those files to change text without touching layout components.
